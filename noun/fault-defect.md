# Topic: Fault, Defect

## Fault, Defect, Malfunction

| **Hebrew**    | **Transcription** | **Meaning**                | **Example**                                         |
| ------------- | ----------------- | -------------------------- | --------------------------------------------------- |
| **תַּקָּלָה**     | *takalá*          | malfunction, fault, glitch | **תקלה במערכת** – a system malfunction.             |
| **פְּגָם**      | *pgám*            | defect, flaw, fault        | **פגם בייצור** – a manufacturing defect.            |
| **לִיקּוּי**    | *likúi*           | defect, deficiency, fault  | **ליקוי בטיחותי** – a safety defect.                |
| **בָּאג**      | *bag*             | bug                        | **יש באג בתוכנה** – there is a bug in the software. |
